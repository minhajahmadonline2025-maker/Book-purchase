📥 Import Students
Upload a CSV or JSON file to add students. Duplicates (same ADM No in same class) are skipped.
CSV Format
JSON Format
CSV columns (header required):
class,admNo,name

Example rows:
2,1131,Mohammed Aslam
3,1050,Abdul Rahman K
Class can be 1–10. ADM No must be unique within the class.
JSON format — object keyed by class number:
{"2":[["1131","Mohammed Aslam"],["1132","Ahmed Razi"]],"3":[["1200","Abdul Rahman"]]}

Or export existing students (JSON) and edit the file.

📥 Import Books & Prices
Upload a JSON file exported from this app, or a manually created one.
JSON format:
{"2":[{"n":"Book Name","p":50,"nb":0},{"n":"Notebook","p":50,"nb":1}],"3":[...]}

Fields: n = book name  |  p = price (₹)  |  nb = 0 (regular) or 1 (notebook)
Tip: Export Books JSON first, edit, then re-import.
